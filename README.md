# 忍彩かくれんぼ — 城旗争奪

「見つからずに近づく。仲間が気を引く。その隙に、城の旗を掴め。」
擬態かくれんぼで城の旗を先に掴む **3対3の忍者ゲーム**（CryptoNinja非公式ファンゲーム）。
素のHTML/CSS/JS・外部ライブラリなし・通信なし・課金なし・オフライン可のPWA。

設計の正本は Codex 出力の設計書 `game-blueprint.md`（2026-09-22・`C:\Users\3mori\Documents\Codex\2026-09-22\https-vibe-co-jp-luna-occulta-3\outputs\`）。
本作はその **単一端末向けの試作** で、設計書との差分は下の「設計書からの変更点」に書く。

## 遊び方
- **練習（90秒の導入）**：移動 → 竹の柄で擬態して刃をやり過ごす → 布の揺れを見つけて見破り → 印を当ててHPを削り露見させる → 咲耶の陽動の隙に旗を掴む。達成条件で進み、時間切れでは追い出さない
- **ひとりで対戦**：忍者（CryptoNinja公式39体から選ぶ・能力値6軸と固有技が1体ずつ違う）→ チーム（青○/橙△）→ 担当（先行/索敵/陽動）→ 味方2人の担当 → 相手の強さ → 作戦会議15秒（城の全階の地図にルート表示・「出発」で短縮）→ 3秒カウント → 試合（やさしい4分・ふつう5分・てごわい6分）＋延長60秒
- **毎試合ちがう城**（下の「城ダンジョン」）。地下〜5階、5種の城が順に巡る。練習だけは固定マップ「竹影の城」
- 勝ち：城のどこかにある旗の半径1mで「旗を掴む」。同tickの両チーム取得は「同着・両チーム優勝」。延長でも未取得なら引き分け
- 擬態：竹（縦縞）・石（斑点）・木（横木目）の柄の上で止まって「布」。0.8秒で成立、最大15秒、解除後6秒回復。柄の外へ出ると即解除。旗の半径3mは擬態不可
- 見破り：前方100°・6m・0.25秒後判定・回復10秒。当たった敵は3秒間、味方全員に輪郭が見える
- 印投げ：弾速14m/s・射程8m・回復2.5秒。当たると擬態解除＋発見3秒＋1秒減速＋HPが減る（基本34）。HPが0になると12秒の「露見」（下の「HP・露見・手当」）。旧ルールの「2発目で帰還」は廃止
- 固有技（Xボタン）と奥義（Lv5・Z）：39体それぞれの技（下の「39体の能力値と固有技」）。チーム経験値でLv1→5、上がるたびに 影/技/護 の系統を選ぶ
- 旗から4m以内に8秒居座ると足元に波紋（敵味方共通）
- 合図3種（こっちへ／敵がいた／旗へ行く）。自由チャットなし

## 城ダンジョン（毎試合ちがう城・2026-09-25）
設計図 `docs/castle-dungeon-blueprint.txt`（ユーザー提供・`.gitignore` で公開しない）を `castle.js` に実装。**勝ち方・HP・固有技の強さは難易度で変えない。変わるのは地形と情報だけ**。
- **階**：地下1F〜5F。1Fが両陣営の開始階。やさしい＝B1/1F/2Fの3階・1階あたり7〜10室・分岐1〜2・旗の階と部屋を最初から表示・4分／ふつう＝B1〜4Fから4〜5階・9〜13室・分岐2〜3・旗の階だけ表示（誰かが旗を見ると部屋も分かる）・5分／てごわい＝5〜6階（5F天守が必須）・11〜16室・分岐3〜4・**候補3室**だけ表示（上の3階に1室ずつ・本物はそのどれか＝5Fとは限らない・名前も同じ呼び方。旗印を見ると偽が1つ消える／部屋の中が見えても消える）・6分
- **城型5種**（シャッフルバッグで巡る＝直前と同じ城は出ない）：竹影城（擬態と抜け道：床下通路・音の少ない縁側／罠＝**鳴子**：踏むと3秒だけ足跡が敵に見える）／水鏡城（水路と開閉水門・浅瀬＝遅い・窓／罠＝**急流**：2m押し流す・HPは減らない）／焔櫓城（吹抜けの大広間・火見櫓＝視程+6m・階段多め／罠＝**火鉢**：8ダメージ・HP1未満にならない・経験値なし）／絡繰城（回転壁＝時間で開閉・押し壁／罠＝**押し壁**：黄黒の帯・予告1秒ののち隣の部屋へ押す）／月霧城（霧の庭＝視線を遮る・似た名前の部屋・月明かりの窓／罠＝**幻灯**：偽の足音4秒）
- **生成の手順（castle.js）**：seed（xmur3→sfc32・128bit）→ 使う階と旗の階 → 開始部屋・旗の間・上下接続の必須モジュール（8mモジュール・階段室は前の接続から2部屋以上離す＝各階を歩かせる）→ 部屋を育てる（**部屋数は大部屋を1つと数えて範囲に収める**）→ 全域木＋分岐 → 最大流で**辺素な経路2本（てごわい3本）**を確保 → 分岐の一部を鍵の扉・床下通路・仕掛け扉に（経路本数は普通の扉だけで満たす）→ 袋小路を上限内に → マス目を刻む（扉の位置をずらして長い射線を作らない）→ 擬態帯・罠・城型の特徴・袋小路の目的（鍵/窓/祠/スイッチ）・旗印 → **左右を鏡写し**して全階を横に並べた1枚の地図にする → 18m超の射線に柱 → 受け入れ条件10項目を検査して、1つでも落ちたら seed を変えて作り直す（最大60回）
- **受け入れ条件10項目**（`Castle.verify`）：到達可能性（鍵なし・仕掛け扉の両位相）／公平性（最短差5%以内・曲がり角差±1）／独立経路／上下移動（各階の入口・出口2つ以上）／袋小路（上限内・必ず目的つき）／射線（開始地点どうし・開始地点と旗の直線視認なし・18m超は遮蔽）／罠（予告つき・迂回できる・環境ダメージでHP1未満にならず経験値なし）／復帰（12秒以内に自陣へ・敵は陣地に入れない）／絡繰変更（敷居に人がいる間は閉めない・旗への全経路を同時に閉じない）／旗室（擬態禁止3m・侵入口2つ以上・近くに罠や落下なし）
- **マス記号**：`^` 上り階段／`v` 下り階段／`z` 降下口（一方通行・必須経路には使わない）／`x` 窓（通れないが見える）／`L` 鍵の扉／`m`・`M` 仕掛け扉（開・閉）／`u` 床下通路（しゃがみ速度・足音小）／`q` 縁側（足音小）／`=` 浅瀬（0.8倍速）／`y` 火見櫓／`H` 祠（静かに2秒でHP+25・20秒に1回）／`S` 近道スイッチ／罠 `n` 鳴子・`c` 急流・`f` 火鉢・`l` 幻灯・`p` 押し壁
- **鍵は任意目標**：拾うとチームの鍵+1、鍵の扉（近道）に触れると開く。旗への道には要らない
- **Bot**：旗が分からない間は候補の部屋を手分けして見に行き（旗の上は踏まずに3m手前で止まる＝見つけた瞬間に掴んで終わらせない）、分かったらルートへ戻る。待ち・攻め時は試合の長さに合わせて伸ばす（`p.ai.tscale`）
- **伏せた旗が漏れない**（レビューで直した点）：コンパスは旗の場所が分かっていて同じ階のときだけ出す／旗の台座は「候補3室」のときだけ（ふつうは描かない）／旗の4m以内で出る波紋は、旗を知らないチームには敵の分を送らない・描かない／上下移動・罠・祠・鍵の効果は視程と射線の内側だけ（部屋サーバーも同じ）／オンラインの端末もサーバーと同じ設置物・霧庭で視線を判定（`Sim.rebuildDyn`）／再接続で受け取り済みのログ・効果を二度鳴らさない
- **表示**：見ている人の階だけを描く（床の事前描画も階ごと）。ミニマップは今の階＋「旗◯F／旗？」、候補の部屋は点線。旗と砂の輪は「チームが見つけた」か「いま見えている」ときだけ描く（ふつう・てごわいで位置が漏れない）。HUDの上に「城の名前｜いま◯F｜旗の情報｜🔑」。作戦会議は全階を格子に並べてルートを表示
- **オンライン**：部屋サーバーが「合言葉・何試合目か・サーバー乱数（128bit）」から seed を作り、城型はロビーに保存したシャッフルバッグで巡る。開始の知らせに城の spec（seed・難易度・城型）を載せ、**端末は同じ spec から同じ城を組み立てる**（地形は送らない）。鍵の扉・仕掛け扉・拾われた鍵は `ms`、旗の情報は `intel`（自分のチームの分だけ）で差分を配る。再接続の全量スナップショットにも spec が乗る
- **検査**：`node tools/castletest.js 40`（受け入れ条件10項目・再現性・左右対称・階数と部屋数の範囲・候補3室・ルート数・城型の巡回・エンジンに載せて30秒）／`node tools/simtest.js 40 hard`（城でBot同士・`--legacy` で固定マップ）／`node tools/roomtest.mjs`（開始の知らせの spec から同じ城・再戦で城型が続かない・再接続）
- **見た目の確認（課金なし・Edgeヘッドレス）**：`python tools/castle_shot.py --seed x --dif hard --type karakuri --at push --out shot.png`（`tools/castle_view.html`＝城を生成してBotで進め、視点・ミニマップ・作戦地図を描く。`--at fog|mech|push|lock|key|emblem|stair|trap|shrine` で見たい物のそばへ）／`tools/game_drive.html`（本物の画面を iframe で開いてひとり用の城の試合を進める）／`tools/online_drive.html`（部屋サーバーの本物のコードをページ内で動かし、ゲームの WebSocket だけ差し替えてオンラインの画面側を確かめる。wrangler dev が使えないときの代わり）。いずれも preview（port 8668）経由で開く検証用ページで、保存は消さない

## HP・露見・手当
- 印が当たると相手のHPが減る（基本34。攻撃の能力値1段ごとに±12%、防御1段ごとに∓8%）。HPは100、チームレベルで最大120。被弾後0.6秒は無敵、3秒は輪郭が見える。HPが30未満だと擬態できない
- HPが0になると12秒の**正体露見**：移動70%（逃走の能力値で増減）・合図だけ可・擬態/攻撃/旗取得は不可・敵から常時見える。試合から消えることはない
- 復帰は2通り：味方が1.5m以内で3秒静止すると**手当**（HP35で復帰。護Lv4「手当上手」なら2.3秒/HP45）／自陣に入るか12秒たつと**自動帰還**して全回復（従来の returning/protect）
- 印の「2回で帰還」は廃止。`p.marks` は互換のため 1 が入ることがあるが表示には使わない。数値の正本は `balance.js` の `BALANCE.hp`（`data.js` の `RULES.hp` が同じものを指す）。設計図は `docs/hp-level-blueprint.txt`

## チーム経験値とレベル（系統 影/技/護・奥義）
- 経験値は**チーム共有**（青・橙で別々）。行動と点：新しく見破る **+12**（同じ敵からは10秒に1度・擬態解除まで成功した時だけ）／有効な一撃 **+3**（無敵・露見・自陣保護中への攻撃は0）／HPを0にする **+12**（同じ敵の再露見から20秒は0・とどめ役に個人加点なし）／手当で復帰 **+10**（最後まで成立した時だけ）／擬態で中央線を越える **+8**（復帰ごとに1回）／旗の周囲4mを確保 **+8/3秒**（生存人数が相手より多い時だけ・チームで1回分）
- 80・200・360・560 XPでLv2〜5（HP最大 105/110/115/120）。上がるたびに各自が**5秒以内に系統を選ぶ**（入力 `tree:影`/`tree:技`/`tree:護`）。選ばなければ推奨系統（`balance.js` の `tree`。「選択」の久遠・ササガネは担当から自動＝先行→影・索敵→技・陽動→護）。毎レベル別の系統を選んでもよい
- 系統の効果（Lv2/3/4/5）：**影**＝音無し足（忍び足+10%）/残り香断ち（可視化-0.5秒）/擬態熟練（持続+3秒・開始-0.1秒）/**奥義・影渡り**（5秒だけ擬態移動が通常の70%・旗3m内で解除）／**技**＝早印（印CD-0.15秒）/広眼（見破り半径+0.5m）/忍術研鑽（固有技CD-15%）/**奥義・再演**（固有技CDを即時完了）／**護**＝厚布（被ダメ-4%）/最初の一印（満タン後の初撃-5・15秒に1度）/手当上手（2.3秒/HP45）/**奥義・不退陣**（8秒間・4m内の味方の被ダメ-12%）。文言と数値の正本は `BALANCE.trees`
- 奥義は Lv5 の系統に付く**一試合一度**の技（入力 `ult`・PCはZ）。試合開始時は全員Lv1で、恒久レベルはない（設計図「恒久レベルで性能差を付けず」）

## 39体の能力値と固有技
- **正本は `balance.js`**（`BALANCE.chars[39]`＝id/番号/役割/肩書き/能力値6軸/推奨系統/固有技 `{name,cd,kind,effect,counter,params}`/勝ち筋/逃げ方）。設計図2枚 `docs/character-balance-blueprint.txt`（39体）・`docs/hp-level-blueprint.txt`（HP・レベル）から起こしたもので、**手直しは `balance.js` で行う**（tools が読むのもこのファイル）。`data.js` が読み込み時に `CHARS` へ併合し（`stats/skill/tree/title/roleLabel/winPlan/escapePlan`）、`sim.js` の `balanceFor()` が係数に変換する
- 能力値は速さ・擬態・攻撃・防御・索敵・逃走の1〜5（3が共通値・**合計は全員21**）。見た目の大きさと当たり判定は全員同じ
- 固有技は1体1つ（`kind` 39種で重複なし・回復16〜28秒・PCはX）。敵を倒さず「発見・足止め・護衛・逃走」を作り、必ず対処法（予告・射程・静止・見える設置物）がある。久遠の猫の目は `skill:white`/`skill:black` で選ぶ（無指定なら自動）。同じ技の重複は加算せず長い残り時間だけ残る
- **設計図の「印」はHP制に読み替える**（`balance.js` の `notes`）：「印の残り時間」＝被弾後の可視化の残り時間（守り兎＝8秒以内の最初の被弾は減速なし・可視化なし／円光＝可視化を2秒短縮）、「自分の印を一つ消す」＝HP回復15（身代札・HP満タンだと使えない）。狐駆けの「1.5m以内で自動発見」は既定の近距離発見2.1mで満たし、布の揺れ＝擬態中の足音がしゃがみと同じ3mまで届く。影穴は「入口→6秒以内に入口のそばでもう一度押す→向いた方向・入口から5m以内（柄の上を優先）へ出口を置いて移動→3秒間、敵が一人だけ追える」
- **属性の相殺**：水遁（水鏡）は敵の残火を即座に消し、敵の狐火を一つ消す／火遁（残火・焙烙玉）は敵の水鏡を2秒短縮／風遁（追風）は敵の紫煙・花びらを押し流して残り時間を半分に／見破りで漆黒を1秒短縮／印で白蛇を消せる／焙烙玉は遮蔽物の裏には届かず、分身をまとめて消す
- **決定論テスト**：`node tools/rpgtest.js`（193件）＋部屋サーバーの `node tools/roomtest.mjs`（切断中の再戦・ログの観戦者フィルタ）＝HP・露見・手当・XP・レベル・系統・奥義・能力値係数・39種の発動・技ごとの効き目・レビュー指摘（設計図との突き合わせ87件）の回帰。**sim.js を直したら必ず通す**
- 図鑑で能力値・技の効果と対処・勝ち筋を確認できる。読み込み順は **chars.js → balance.js → castle.js → data.js → sim.js**（`index.html`・`sw.js` の CORE・`tools/build_worker.py` で同じ順。`tools/inspect.py` が順序を検査する）

## 合格基準と simtest の見方
- `node tools/simtest.js 40 normal` でBot同士40試合を無人で回すと、末尾に「--- 合格基準（HP・レベル設計図）---」の行が出る：HP0（1人あたり/試合・目安1〜3）／露見→復帰の平均秒（6〜9・手当/自陣/自動帰還の内訳）／レベル差1以内の時間（80%以上）／Lv5到達率（30〜50%）／ダメージ由来XP（35%以下・内訳つき）／固有技の発動回数（kind別）
- Bot同士は30〜40秒前後で決着するため、HP0・Lv5到達・ダメージ由来XPは目安に届かない（2026-09-24時点：HP0 0.2回・露見→復帰7.3秒・Lv5 0%・ダメージ由来XP 90%）。**合格の本判定は人間込みのプレイテスト**（設計図「初回テストの合格線」＝役割別の勝率45〜55%と「対処法を理解できたか」）。`tools/inspect.py` はこの5つを「注意」として表示し、NGにはしない
- `--fixed` で旧来の3体固定。再戦後に状態（HP・レベル・設置物・技CD）が残ればテストは失敗で止まる

## 設計書からの変更点（試作の判断）
- **通信対戦→単一端末**：GitHub Pagesでは権威サーバーを置けないため、味方2人・相手3人は端末内Bot。Botは人間と同じ可視判定（`canSee`）＋視野220°で動き、擬態・見破り・印・合図・帰還を使う。判定は将来サーバーへ移せる構造（`sim.js` のみで完結）
- **三人称3D→見下ろし2D**：キャラクターシートの4方向（まえ/ななめ/よこ/うしろ）をそのままスプライトに使う。視界は壁で遮られた側を暗くし、見えていない敵は描かない。敵の擬態は布だけを描き、動くと布が揺れる
- **作戦15秒**：単一端末では「担当（先行/索敵/陽動）を味方に割り当てる」画面にした。担当はBotの行動方針になる（先行＝竹回廊で待ち伏せ→隙に突入／索敵＝旗の手前で見張り・侵入者と競り合う／陽動＝覗き→撃つ→下がる）
- **旗まわりの速攻対策**：設計書が最初に検証せよとした「走るだけで勝つ」を、Botの「旗に迫る敵より自分が近ければ先に掴む」競り合いと、開始30秒までは突入しない待ちで抑えた。Bot同士では初回取得が平均27秒・20秒未満は約1/4（`simtest.js`）。人間込みの実測で再調整する
- **固定マップ→毎試合生成の城（2026-09-25）**：試合は `castle.js` が生成する城で行う。固定マップ「竹影の城」は練習（チュートリアル）と回帰テスト（`rpgtest.js`・`simtest.js --legacy`）に残す
- マップ「竹影の城」は設計書の概念図（3ルート・4入口・目隠し塀・旗の砂地）を64×48のグリッドで施工。経路長は中央約40m/北約66m/南約66m（設計目標36/54/63の比率を優先）

## 合言葉の部屋（オンライン対戦・無料）
- タイトル→「合言葉の部屋」→「部屋を作る」で4文字の合言葉が出る。友だちは「合言葉で参加」。最大6人、空きはBotが埋める。ホスト（👑）が相手Botの強さを決めて「開始」→作戦会議15秒（ホストの「出発」で短縮）→試合→結果→ホストが「もう一戦／チーム入替／部屋へ戻る」
- **サーバーは `worker/`**（Cloudflare Workers ＋ Durable Objects・無料枠）。合言葉ごとに1つの部屋オブジェクトが `sim.js` を30Hzで回し、15Hzで観戦者ごとに見える情報だけを配る（壁の向こうの敵は送らない・擬態中の敵は布の位置だけ・足音は方向だけ）。入力は「方向と行動」だけ＝設計書09どおり（`skill`/`skill:white`/`ult`/`tree:影` 等も文字列のまま通す）。自分の移動だけ端末で先読みし、ずれたらサーバーに合わせる
- スナップショットには `objects`（設置物・敵の分身は布として）・`xp`・`level`、効果には `dmg/hp/level/tree/tx/ty/r/decoy` も入る。ログ（hit/expose/recover/healed/levelup/perk/ult/skill/countered）は `sim.js` が積んだ項目をそのまま差分で送る。試合終了の `end` には各自の `stats`（damage/hp0/heals/skills…）とチームの `level`/`xp` が付く
- 切断は20秒の猶予で自動再接続。戻らなければBotが引き継ぐ。誰もいない部屋は30分で消える。オンライン中はポーズできない（メニューから退室だけ）
- 城ダンジョン：開始の知らせ（`start`）に城の spec を載せ、端末が同じ城を組み立てる。スナップショットに `ms`（鍵の扉・仕掛け扉・拾われた鍵）・`intel`（自分のチームの旗の情報）・`keys`・`duration` が乗る
- 公開手順：`★オンライン部屋サーバーを公開する.bat`（`tools/build_worker.py` で判定ロジック chars/balance/data/castle/sim を同梱→`npx wrangler deploy`。初回だけ `npx wrangler login`）。公開URLが `data.js` の `ONLINE.url` と違えば書き換えて再公開するか、設定画面の「オンラインのサーバーURL」に貼る
- ローカル確認：`cd worker && npx wrangler dev --port 8788 --local` → ゲームの設定で URL を `http://127.0.0.1:8788` に。2タブで部屋を作る／参加すれば1台で試せる。**wrangler の更新で新しい workerd.exe がWindowsに止められたとき（spawn EPERM）**は `tools/online_drive.html` で画面側を確かめる（セキュリティ設定は変えない）
- 無料枠の目安：Durable Objects の受信メッセージは休止API利用で20:1換算。入力20Hz×6人の4分試合で約1,500リクエスト＝1日10万の枠で60試合超

## キャラクター（CryptoNinja 公式39体）
- **正本は `chars.js`**（`tools/build_chars.py` が `cnp-3d/ref_official/roster.json`＝公式名簿から生成）。番号・和名・英名・クラン・忍術・武器・誕生日・紹介文・パレット・見た目メモを持つ
- **ゲーム内スプライト**：狐白・咲耶・刃は手描きシート由来の4方向＋表情（`tools/prep_assets.py`）。残り36体は**公式3Dフィギュア画像**（`cnp-3d/ref_official/3d/`）を白背景から切り抜いた正面の立ち絵で、左右反転だけで向きを表す（`render.js` の `spriteFor` が自動で判定）。表情スプライトが無いキャラは「！」「♪」の記号で代用
- **顔アイコン・図鑑の肖像**：公式2Dイラスト（`cnp-3d/ref_official/2d/`）から `img/faces/`（96px）と `img/art/`（360px）
- **資料シート**：`tools/build_sheets.py` が公式2D・公式3Dフィギュア・公式データ・パレットを1枚（1536×1024）にまとめる（Edgeヘッドレス・課金なし）→ `img/sheets/<id>.jpg`。図鑑の「資料シート」から見られる
- **手描き風「ゲーム用アレンジ案」を36体ぶん作る**：`docs/image-prompts_39.txt` に狐白と同じ骨格の生成プロンプトがある（参照画像は公式2D/3D）。生成したシートPNGは `python tools/prep_assets.py --auto <sheet.png> <id>` で4方向＋しぐさを自動で切り出し、`img/chars/<id>_*.png` を置き換えると次からその4方向スプライトが使われる
- ロビーは39体のグリッドから選ぶ。味方2人は「おまかせ」（毎回変わる）か指名。相手3人はランダム（同じキャラが両チームにいてもよい）
