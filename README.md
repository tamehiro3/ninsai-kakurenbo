# 忍彩かくれんぼ — 城旗争奪

「見つからずに近づく。仲間が気を引く。その隙に、城の旗を掴め。」
擬態かくれんぼで城の旗を先に掴む **3対3の忍者ゲーム**（CryptoNinja非公式ファンゲーム）。
素のHTML/CSS/JS・外部ライブラリなし・通信なし・課金なし・オフライン可のPWA。

設計の正本は Codex 出力の設計書 `game-blueprint.md`（2026-09-22・`C:\Users\3mori\Documents\Codex\2026-09-22\https-vibe-co-jp-luna-occulta-3\outputs\`）。
本作はその **単一端末向けの試作** で、設計書との差分は下の「設計書からの変更点」に書く。

## 遊び方
- **練習（90秒の導入）**：移動 → 竹の柄で擬態して刃をやり過ごす → 布の揺れを見つけて見破り → 印を当ててHPを削り露見させる → 咲耶の陽動の隙に旗を掴む。達成条件で進み、時間切れでは追い出さない
- **ひとりで対戦**：忍者（CryptoNinja公式39体から選ぶ・能力値6軸と固有技が1体ずつ違う）→ チーム（青○/橙△）→ 担当（先行/索敵/陽動）→ 味方2人の担当 → 相手の強さ → 作戦会議15秒（地図にルート表示・「出発」で短縮）→ 3秒カウント → 試合240秒＋延長60秒
- 勝ち：中央の旗の半径1mで「旗を掴む」。同tickの両チーム取得は「同着・両チーム優勝」。延長でも未取得なら引き分け
- 擬態：竹（縦縞）・石（斑点）・木（横木目）の柄の上で止まって「布」。0.8秒で成立、最大15秒、解除後6秒回復。柄の外へ出ると即解除。旗の半径3mは擬態不可
- 見破り：前方100°・6m・0.25秒後判定・回復10秒。当たった敵は3秒間、味方全員に輪郭が見える
- 印投げ：弾速14m/s・射程8m・回復2.5秒。当たると擬態解除＋発見3秒＋1秒減速＋HPが減る（基本34）。HPが0になると12秒の「露見」（下の「HP・露見・手当」）。旧ルールの「2発目で帰還」は廃止
- 固有技（Xボタン）と奥義（Lv5・Z）：39体それぞれの技（下の「39体の能力値と固有技」）。チーム経験値でLv1→5、上がるたびに 影/技/護 の系統を選ぶ
- 旗から4m以内に8秒居座ると足元に波紋（敵味方共通）
- 合図3種（こっちへ／敵がいた／旗へ行く）。自由チャットなし

## HP・露見・手当
- 印が当たると相手のHPが減る（基本34。攻撃の能力値1段ごとに±12%、防御1段ごとに∓8%）。HPは100、チームレベルで最大120。被弾後0.6秒は無敵、3秒は輪郭が見える。HPが30未満だと擬態できない
- HPが0になると12秒の**正体露見**：移動70%（逃走の能力値で増減）・合図だけ可・擬態/攻撃/旗取得は不可・敵から常時見える。試合から消えることはない
- 復帰は2通り：味方が1.5m以内で3秒静止すると**手当**（HP35で復帰。護Lv4「手当上手」なら2.3秒/HP45）／自陣に入るか12秒たつと**自動帰還**して全回復（従来の returning/protect）
- 印の「2回で帰還」は廃止。`p.marks` は互換のため 1 が入ることがあるが表示には使わない。数値の正本は `balance.js` の `BALANCE.hp`（`data.js` の `RULES.hp` が同じものを指す）。設計図は `docs/hp-level-blueprint.txt`

## チーム経験値とレベル（系統 影/技/護・奥義）
- 経験値は**チーム共有**（青・橙で別々）。行動と点：新しく見破る **+12**（同じ敵からは10秒に1度・擬態解除まで成功した時だけ）／有効な一撃 **+3**（無敵・露見・自陣保護中への攻撃は0）／HPを0にする **+12**（同じ敵の再露見から20秒は0・とどめ役に個人加点なし）／手当で復帰 **+10**（最後まで成立した時だけ）／擬態で中央線を越える **+8**（復帰ごとに1回）／旗の周囲4mを確保 **+8/3秒**（生存人数が相手より多い時だけ・チームで1回分）
- 80・200・360・560 XPでLv2〜5（HP最大 105/110/115/120）。上がるたびに各自が**5秒以内に系統を選ぶ**（入力 `tree:影`/`tree:技`/`tree:護`）。選ばなければ推奨系統（`balance.js` の `tree`。「選択」の久遠・ササガネは担当から自動＝先行→影・索敵→技・陽動→護）。毎レベル別の系統を選んでもよい
- 系統の効果（Lv2/3/4/5）：**影**＝音無し足（忍び足+10%）/残り香断ち（可視化-0.5秒）/擬態熟練（持続+3秒・開始-0.1秒）/**奥義・影渡り**（5秒だけ擬態移動が通常の70%・旗3m内で解除）／**技**＝早印（印CD-0.15秒）/広眼（見破り半径+0.5m）/忍術研鑽（固有技CD-15%）/**奥義・再演**（固有技CDを即時完了）／**護**＝厚布（被ダメ-4%）/最初の一印（満タン後の初撃-5・15秒に1度）/手当上手（2.3秒/HP45）/**奥義・不退陣**（8秒間・4m内の味方の被ダメ-12%）。文言と数値の正本は `BALANCE.trees`
- 奥義は Lv5 の系統に付く**一試合一度**の技（入力 `ult`・PCはZ）。試合開始時は全員Lv1で、恒久レベルはない（設計図「恒久レベルで性能差を付けず」）

## 39体の能力値と固有技
- **正本は `balance.js`**（`BALANCE.chars[39]`＝id/番号/役割/肩書き/能力値6軸/推奨系統/固有技 `{name,cd,kind,effect,counter,params}`/勝ち筋/逃げ方）。設計図2枚 `docs/character-balance-blueprint.txt`（39体）・`docs/hp-level-blueprint.txt`（HP・レベル）から起こしたもので、**手直しは `balance.js` で行う**（tools が読むのもこのファイル）。`data.js` が読み込み時に `CHARS` へ併合し（`stats/skill/tree/title/roleLabel/winPlan/escapePlan`）、`sim.js` の `balanceFor()` が係数に変換する
- 能力値は速さ・擬態・攻撃・防御・索敵・逃走の1〜5（3が共通値・**合計は全員21**）。見た目の大きさと当たり判定は全員同じ
- 固有技は1体1つ（`kind` 39種で重複なし・回復16〜28秒・PCはX）。敵を倒さず「発見・足止め・護衛・逃走」を作り、必ず対処法（予告・射程・静止・見える設置物）がある。久遠の猫の目は `skill:white`/`skill:black` で選ぶ（無指定なら自動）。同じ技の重複は加算せず長い残り時間だけ残る
- **設計図の「印」はHP制に読み替える**（`balance.js` の `notes`）：「印の残り時間」＝被弾後の可視化の残り時間（守り兎＝8秒以内の最初の被弾は減速なし・可視化なし／円光＝可視化を2秒短縮）、「自分の印を一つ消す」＝HP回復15（身代札・HP満タンだと使えない）。狐駆けの「1.5m以内で自動発見」は既定の近距離発見2.1mで満たし、布の揺れ＝擬態中の足音がしゃがみと同じ3mまで届く。影穴は「入口→6秒以内に入口のそばでもう一度押す→向いた方向・入口から5m以内（柄の上を優先）へ出口を置いて移動→3秒間、敵が一人だけ追える」
- **属性の相殺**：水遁（水鏡）は敵の残火を即座に消し、敵の狐火を一つ消す／火遁（残火・焙烙玉）は敵の水鏡を2秒短縮／風遁（追風）は敵の紫煙・花びらを押し流して残り時間を半分に／見破りで漆黒を1秒短縮／印で白蛇を消せる／焙烙玉は遮蔽物の裏には届かず、分身をまとめて消す
- **決定論テスト**：`node tools/rpgtest.js`（171件）＝HP・露見・手当・XP・レベル・系統・奥義・能力値係数・39種の発動・技ごとの効き目・レビュー指摘（設計図との突き合わせ87件）の回帰。**sim.js を直したら必ず通す**
- 図鑑で能力値・技の効果と対処・勝ち筋を確認できる。読み込み順は **chars.js → balance.js → data.js → sim.js**（`index.html`・`sw.js` の CORE・`tools/build_worker.py` で同じ順。`tools/inspect.py` が順序を検査する）

## 合格基準と simtest の見方
- `node tools/simtest.js 40 normal` でBot同士40試合を無人で回すと、末尾に「--- 合格基準（HP・レベル設計図）---」の行が出る：HP0（1人あたり/試合・目安1〜3）／露見→復帰の平均秒（6〜9・手当/自陣/自動帰還の内訳）／レベル差1以内の時間（80%以上）／Lv5到達率（30〜50%）／ダメージ由来XP（35%以下・内訳つき）／固有技の発動回数（kind別）
- Bot同士は30秒前後（ふつう）で決着するため、HP0・Lv5到達・ダメージ由来XPは目安に届かない（2026-09-24時点：HP0 0.2回・露見→復帰7.3秒・Lv5 0%・ダメージ由来XP 90%）。**合格の本判定は人間込みのプレイテスト**（設計図「初回テストの合格線」＝役割別の勝率45〜55%と「対処法を理解できたか」）。`tools/inspect.py` はこの5つを「注意」として表示し、NGにはしない
- `--fixed` で旧来の3体固定。再戦後に状態（HP・レベル・設置物・技CD）が残ればテストは失敗で止まる

## 設計書からの変更点（試作の判断）
- **通信対戦→単一端末**：GitHub Pagesでは権威サーバーを置けないため、味方2人・相手3人は端末内Bot。Botは人間と同じ可視判定（`canSee`）＋視野220°で動き、擬態・見破り・印・合図・帰還を使う。判定は将来サーバーへ移せる構造（`sim.js` のみで完結）
- **三人称3D→見下ろし2D**：キャラクターシートの4方向（まえ/ななめ/よこ/うしろ）をそのままスプライトに使う。視界は壁で遮られた側を暗くし、見えていない敵は描かない。敵の擬態は布だけを描き、動くと布が揺れる
- **作戦15秒**：単一端末では「担当（先行/索敵/陽動）を味方に割り当てる」画面にした。担当はBotの行動方針になる（先行＝竹回廊で待ち伏せ→隙に突入／索敵＝旗の手前で見張り・侵入者と競り合う／陽動＝覗き→撃つ→下がる）
- **旗まわりの速攻対策**：設計書が最初に検証せよとした「走るだけで勝つ」を、Botの「旗に迫る敵より自分が近ければ先に掴む」競り合いと、開始30秒までは突入しない待ちで抑えた。Bot同士では初回取得が平均27秒・20秒未満は約1/4（`simtest.js`）。人間込みの実測で再調整する
- マップ「竹影の城」は設計書の概念図（3ルート・4入口・目隠し塀・旗の砂地）を64×48のグリッドで施工。経路長は中央約40m/北約66m/南約66m（設計目標36/54/63の比率を優先）

## 合言葉の部屋（オンライン対戦・無料）
- タイトル→「合言葉の部屋」→「部屋を作る」で4文字の合言葉が出る。友だちは「合言葉で参加」。最大6人、空きはBotが埋める。ホスト（👑）が相手Botの強さを決めて「開始」→作戦会議15秒（ホストの「出発」で短縮）→試合→結果→ホストが「もう一戦／チーム入替／部屋へ戻る」
- **サーバーは `worker/`**（Cloudflare Workers ＋ Durable Objects・無料枠）。合言葉ごとに1つの部屋オブジェクトが `sim.js` を30Hzで回し、15Hzで観戦者ごとに見える情報だけを配る（壁の向こうの敵は送らない・擬態中の敵は布の位置だけ・足音は方向だけ）。入力は「方向と行動」だけ＝設計書09どおり（`skill`/`skill:white`/`ult`/`tree:影` 等も文字列のまま通す）。自分の移動だけ端末で先読みし、ずれたらサーバーに合わせる
- スナップショットには `objects`（設置物・敵の分身は布として）・`xp`・`level`、効果には `dmg/hp/level/tree/tx/ty/r/decoy` も入る。ログ（hit/expose/recover/healed/levelup/perk/ult/skill/countered）は `sim.js` が積んだ項目をそのまま差分で送る。試合終了の `end` には各自の `stats`（damage/hp0/heals/skills…）とチームの `level`/`xp` が付く
- 切断は20秒の猶予で自動再接続。戻らなければBotが引き継ぐ。誰もいない部屋は30分で消える。オンライン中はポーズできない（メニューから退室だけ）
- 公開手順：`★オンライン部屋サーバーを公開する.bat`（`tools/build_worker.py` で判定ロジック chars/balance/data/sim を同梱→`npx wrangler deploy`。初回だけ `npx wrangler login`）。公開URLが `data.js` の `ONLINE.url` と違えば書き換えて再公開するか、設定画面の「オンラインのサーバーURL」に貼る
- ローカル確認：`cd worker && npx wrangler dev --port 8788 --local` → ゲームの設定で URL を `http://127.0.0.1:8788` に。2タブで部屋を作る／参加すれば1台で試せる
- 無料枠の目安：Durable Objects の受信メッセージは休止API利用で20:1換算。入力20Hz×6人の4分試合で約1,500リクエスト＝1日10万の枠で60試合超

## キャラクター（CryptoNinja 公式39体）
