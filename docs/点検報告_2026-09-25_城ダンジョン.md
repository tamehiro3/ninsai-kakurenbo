# 忍彩かくれんぼ — 城ダンジョン導入 点検報告（2026-09-25・v6）

依頼：「城の複雑性を盛り込んでアップデートして」（設計図 `castle-dungeon-blueprint`＝`docs/castle-dungeon-blueprint.txt`・非公開）
公開：ゲーム `https://tamehiro3.github.io/ninsai-kakurenbo/`（v6）／部屋サーバー `https://ninsai-room.3moriguchi-3.workers.dev`（再デプロイ済み）

## 結論
- 試合ごとに**地下1F〜5Fの城を自動生成**（`castle.js`）。城型5種をシャッフルバッグで巡回し、難易度で「地形と情報と時間」だけを変える（勝ち方・HP・固有技は同じ）
- 設計図の**受け入れ条件10項目**を毎回検査し、1つでも落ちたら seed を変えて作り直す。**900城でNG 0件**（てごわいの生成は平均44ms・最悪でも作り直し10回）
- 機械点検 `tools/inspect.py`：**NG 0件**（注意2件は従来どおり＝紹介文なし7体／Bot同士の合格基準は参考値）
- レビュー2本（生成器・判定／画面・オンライン）で**実害15件**を見つけて全部直し、回帰テストに残した

## 城型と罠
竹影城（鳴子・床下通路・縁側）／水鏡城（急流・水門・浅瀬・窓）／焔櫓城（火鉢・火見櫓・吹抜け）／絡繰城（押し壁・回転壁）／月霧城（幻灯・霧の庭・窓）。罠はすべて見えていて迂回でき、火鉢でもHP1未満にならず経験値は付かない。

## レビューで直した15件（抜粋）
- 伏せた旗が漏れる：コンパス（薄くしても向きで分かる）／ふつうの台座／旗の砂の輪がミニマップに出る／敵の波紋／レベルアップの輪が旗の位置／作戦地図のルートが本物の旗の間で終わる／上下移動・罠の効果が壁越しに見える → すべて「分かっている・見えている範囲」だけに
- てごわいの本物がいつも5F → 上の3階に候補を1室ずつ置き、本物はそのどれか（名前・柱・擬態帯・階段・降下口の有無もそろえた）
- 公平性：軸の上のスイッチが青側だけ／軸の急流が片側へ流す／左右の押し壁の時刻が1.7秒ずれる → 修正
- 詰み：降下口の着地点に柱／Botが階段の上で立ち往生 → 修正
- オンライン：端末の設置物（霧庭）がサーバーとずれる／再接続で同じ通知が二度鳴る → 修正
- 生成の数え方：部屋数を大部屋1つで数える／ふつうで階が3つになる不具合／絡繰城に押し壁がほぼ出ない → 修正

## 残り・注意
